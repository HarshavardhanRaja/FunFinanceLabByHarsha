# Paisa Panga — Production Guide

> **Series concept:** Head-to-head finance comparisons with real data. Debate-worthy, shareable, data-driven.
> **Brand:** FunFinanceLabByHarsha
> **Companion to:** WTF — What The Finance?

---

## 1. WHAT IS PAISA PANGA?

"Panga" = picking a fight / getting into a mess. 
"Paisa Panga" = money fights — two financial options going head-to-head with real numbers.

The audience picks a side. The data reveals the truth. The truth is usually: "it depends" — but the viewer walks away understanding *when* each option wins.

---

## 2. FORMAT

### Option A: Reel (45–60 sec)
- Hook: Present the matchup dramatically
- Data: Show real numbers, real timeframes
- Twist: The surprising result
- Verdict: Nuanced — when each wins
- CTA: "Which side are you on? Comment below."

### Option B: Carousel (5–6 slides)
- Slide 1: Fight card (Option A vs Option B — dramatic visual)
- Slide 2: The setup (same amount, same period, two choices)
- Slide 3: Option A's performance (with data)
- Slide 4: Option B's performance (with data)
- Slide 5: The verdict (with nuance)
- Slide 6: CTA + cross-link to related WTF LOG

### Visual Style
- "Fight card" aesthetic — dark background, teal vs gold
- Two options facing off
- Data/numbers in the center
- Premium but punchy — think UFC weigh-in card meets Bloomberg
- NOT a boring comparison table

---

## 3. CONTENT RULES

1. **Always use real data.** No made-up numbers. Cite the source or time period.
2. **Never declare an absolute winner.** Show when each option wins and loses.
3. **Include the hidden variable.** Tax impact, inflation adjustment, lock-in period, liquidity — the thing most comparison posts ignore.
4. **End with a WTF LOG cross-link** when one exists.
5. **Caption should invite debate.** The algorithm rewards comments. Frame the verdict as a question.
