## 2. SERIES OVERVIEW

### What is WTF?
"What The Finance?" — a playful educational series that turns financial confusion into understanding. Finance concepts frequently make beginners react "What the…?" — the series transforms that reaction into clarity.

### Tone
- Funny, curious, intelligent
- Beginner-friendly, slightly irreverent
- Never dumbed down

### Core Content Structure
```
HOOK → STORY/ANALOGY → INTUITION → FINANCE CONCEPT → REAL EXAMPLE → TAKEAWAY
```

**Never** start with a textbook definition. Always start with something familiar.

Instead of: "An index fund is a passive investment vehicle..."
Prefer: "Imagine you're asked to build an IPL team before the tournament starts..."

The viewer should think: **"Ohhh… now I understand why this works."** That moment is the brand.

## 4. CONTENT FORMAT PER LOG

### Instagram Carousel (Primary)
- **8–14 slides** (1080×1080 or 1080×1350)
- Slide structure:
  - Slide 1: **HOOK** — curiosity-driven, no definitions
  - Slide 2–3: **STORY** — Arjun's situation / relatable analogy
  - Slide 4–6: **CONCEPT REVEAL** — the financial concept explained through the analogy
  - Slide 7–8: **HUMAN TRANSLATION** — WTF Bot translates jargon to plain language
  - Slide 9: **REAL EXAMPLE** — actual numbers, data, or scenario
  - Slide 10: **STARTER PACK** — 3–4 actionable first steps for beginners
  - Final slide: **CTA** — follow, save, share + teaser for next LOG
- Don't rigidly force slides when fewer are better

### Instagram Reel (Secondary)
- **45–60 seconds**
- Voiceover-driven with visual storytelling
- First 1–2 seconds: strong hook
- Strong payoff/punchline
- Caption with key insight + CTA

### Caption Template
```
[HOOK LINE]

[2-3 line story summary]

🔍 HUMAN TRANSLATION:
[Concept in one plain sentence]

🎒 STARTER PACK:
1. [Action step]
2. [Action step]
3. [Action step]
4. [Action step]

🔮 NEXT MYSTERY: [Teaser for next LOG]

Save this. Share with someone who needs it.
Follow @funfinancelabbyharsha for more.

#WhatTheFinance #WTF #FunFinanceLab #PersonalFinance #[topic-specific hashtags]
```

## 8. HOOK PHILOSOPHY

Hooks should create curiosity. Never start with "Today we're going to learn about..."

**Good hooks:**
- "What if I told you the safest IPL strategy might actually beat most experts?"
- "Five experts. Five different teams. Only one tournament."
- "Your parents say rent is throwing money away. But is it?"
- "₹12,000. Two people. Same fund. Then the market crashed 35%."

**Bad hooks:**
- "Today we're going to learn about index funds."
- "Let me explain what SIP means."
- "Do you know about mutual funds?"

---

## 9. FINANCIAL ACCURACY RULES

- Entertainment should NEVER override financial accuracy
- If an analogy becomes misleading, change the analogy
- Clearly distinguish FACT from INTERPRETATION from SPECULATION
- Use language like "potential," "worth investigating," "risk/reward" — never "guaranteed," "sure-shot," "easy money"
- When dealing with current stocks, IPOs, market prices, regulations — research current information before giving conclusions
- Always cite actual data sources when using specific numbers

---

## 10. VISUAL / AI IMAGE PROMPT RULES

When requesting AI-generated images for slides:
- Specify: aspect ratio, composition, foreground, background, character placement, camera, lens feel, lighting, environment, text, typography, brand colours, visual hierarchy, negative space
- AI-generated text can be unreliable — keep text short and explicit, or plan to overlay text separately
- Never allow incorrect financial numbers or fake company names in visuals
- Maintain dark navy + teal + gold color palette
- Premium finance-tech aesthetic, not generic Canva templates

---

## 11. REEL VOICEOVER DIRECTION

When writing reel scripts, specify:
- Deliberate pauses (marked with `[PAUSE]` or `...`)
- Emphasis on key words (marked with **bold** or CAPS)
- Emotion for each section (curious, shocked, confident, playful)
- Rhythm and pacing (fast buildup → slow reveal → punchy conclusion)
- Should NOT sound like generic AI narration

## 13. CREATOR COLLABORATION STYLE

- Don't just agree with everything — challenge weak ideas constructively
- Preserve decisions made earlier in conversation (continuity matters)
- Work iteratively (slide by slide, scene by scene)
- When there's a choice, prefer the more relatable, more Indian, more visual option
- Ask: "Can this become a repeatable format rather than just one post?"
- Think about: storytelling, financial accuracy, audience retention, visual execution, viral potential
