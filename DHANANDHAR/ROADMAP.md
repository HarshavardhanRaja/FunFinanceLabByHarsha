## 📋 How to Use This Structure

### For Each Season:
1. Open the season folder (e.g., `season_01_the_fire/`)
2. Edit the `README.md` to track season-wide info
3. Each episode has its own folder

### For Each Episode:
1. `README.md` - Episode metadata & links
2. `idea.md` - Core concept & angle
3. `script.md` - Full dialogue breakdown
4. `video/` folder - Raw video files & media

### Status Tracking:
Update the status column as episodes progress through:
- Draft → In Progress → Ready → Published
